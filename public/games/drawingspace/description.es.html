Cómo jugar a Drawing Space

¡Bienvenidos, pequeños artistas del espacio! En Drawing Space, vas a lanzar tu imaginación en una colorida galaxia que tú mismo has creado. Sigue estos simples pasos para hacer tu primera obra maestra cósmica:

1. Selecciona tu Pincel

• Toca o haz clic en el ícono del lápiz.

• Elige entre formas de pincel redondas, puntiagudas o planas.

2. Elige un Color

• Abre la paleta del arcoíris.

• Toca cualquier tono que te guste: verdes brillantes, azules profundos o amarillos resplandecientes.

3. Dibuja tu Escena

• Arrastra tu dedo o ratón para esbozar planetas, cohetes, estrellas o aliens amistosos.

• Experimenta con diferentes tamaños de pinceles para formas grandes o pequeños detalles.

4. Corrige pequeños Errores

• Cambia a la herramienta de borrado.

• Frota suavemente cualquier línea que quieras cambiar.

5. Envía y Brilla

• Presiona el botón verde de “Hecho”.

• Observa cómo tu obra de arte se desplaza hacia la galería pública.

• Gana estrellas según la limpieza y la imaginación.

6. Desbloquea Divertidos Extras

• Usa estrellas para revelar nuevos estilos de pinceles, stickers brillantes y nuevos paquetes de colores.

• Sigue dibujando para crear la colección de arte espacial más genial del universo.

Prepárate para llenar el cosmos con tu creatividad: ¡Drawing Space está esperando tu próxima creación estelar!

Consejos y Trucos para Drawing Space

1. Comienza con Formas Simples

Dibuja grandes círculos para planetas, líneas onduladas para cometas y pequeños puntos para estrellas distantes. Mantener tus trazos de lápiz suaves te permitirá ajustar el diseño hasta que estés satisfecho.

2. Juega con Mezclas de Color

Toma dos o tres crayones, marcadores o pinceles digitales. Mezcla morado con azul o rosa con naranja en cada planeta para darles un resplandeciente y mágico aspecto.

3. Haz que el Cielo Resalte

Sombría el fondo con un profundo azul marino o negro. Luego, usa un bolígrafo gel blanco o un pincel sumergido en pintura blanca para lanzarlo suavemente sobre la página, creando una lluvia de pequeñas estrellas brillantes.

4. Agrega Divertidos Detalles

Utiliza plantillas o stickers sencillos de cohetes, astronautas y amigos alienígenas para llenar tu galaxia de personajes amistosos al instante. ¡A los niños les encanta ver a su tripulación espacial cobrar vida!

5. Termina con Destellos

Traza suavemente los bordes de planetas, cometas y las ventanas de tu cohete con un lápiz plateado o blanco. Esto añade un poco de brillo, haciendo que todo se vea tridimensional y listo para despegar.
